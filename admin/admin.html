Portfolio Content Editor

Local, offline tool. Nothing here is uploaded anywhere — it only reads and writes a data.js file on your own computer.

How this works:
  1. Click Import data.js and select the data.js file from your portfolio folder.
  2. Edit any fields below.
  3. Click Export data.js — a new data.js file downloads.
  4. Replace the old data.js in your portfolio folder with the downloaded one, then commit & push to GitHub (or upload it via the GitHub website) to publish the change.

This page never contacts GitHub or any server, and stores no password or token, because it doesn't need to — publishing still happens through your own GitHub login when you commit the file, which is real authentication GitHub already provides.

Import a data.js file to begin, or click "Start blank" below.
